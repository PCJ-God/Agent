# 负载均衡 SLB

## 什么是负载均衡
负载均衡 SLB（Server Load Balancer）是将访问流量根据转发策略分发到后端多台云服务器上的流量分发控制服务。它可以扩展应用系统的服务能力，消除单点故障，提升应用的可用性。

## 监听与转发规则
SLB 通过监听（Listener）接收客户端请求。监听定义了协议和端口（如 HTTP 80、HTTPS 443、TCP 9000），并根据转发规则将请求分发到后端服务器组。

## 健康检查
SLB 会定期对后端服务器进行健康检查。当某台后端服务器异常时，SLB 自动将流量转发到其他正常的服务器；故障恢复后，SLB 会重新将流量引入该服务器。健康检查保证了业务的高可用。

## 主要类型
- 应用型负载均衡 ALB：七层（HTTP/HTTPS），支持基于内容的高级路由。
- 网络型负载均衡 NLB：四层（TCP/UDP），超高性能，适合游戏、物联网等场景。
- 传统型负载均衡 CLB：四层和七层都支持，是早期的经典产品。
