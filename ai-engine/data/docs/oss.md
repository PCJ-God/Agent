# 对象存储 OSS

## 什么是对象存储 OSS
对象存储 OSS（Object Storage Service）是阿里云提供的海量、安全、低成本、高持久的云存储服务。它适合存放图片、音视频、日志等非结构化数据，提供 99.9999999999%（12 个 9）的数据持久性。

## 核心概念
- Bucket：存储空间，是 OSS 中存储对象的容器，名称全局唯一。
- Object：对象，是 OSS 中存储的基本单元，由元数据和数据组成。
- Key：对象在 Bucket 中的唯一标识，相当于文件的完整路径。
- Region：地域，Bucket 必须属于某个地域。

## 存储类型
OSS 提供多种存储类型以降低存储成本：
- 标准存储：高可靠、高可用，适合频繁访问的数据。
- 低频访问存储：适合访问频率低但需快速读取的数据。
- 归档存储：适合长期保存、访问极少的备份数据，读取前需解冻。
- 冷归档存储：成本最低，适合合规归档等极冷数据。

## 访问控制
OSS 通过 Bucket 权限（公共读、公共读写、私有）和 RAM 策略、STS 临时凭证、签名 URL 等方式控制访问，保证数据安全。
