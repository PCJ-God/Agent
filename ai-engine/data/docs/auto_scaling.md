# 弹性伸缩 Auto Scaling

## 什么是弹性伸缩
弹性伸缩（Auto Scaling）是阿里云提供的根据业务需求和策略自动调整计算资源的管理服务。它可以根据业务负载自动增加或减少 ECS 实例数量，保证业务高峰时够用、低谷时省钱。

## 核心组件
- 伸缩组：弹性伸缩的基本管理单元，定义了同构的 ECS 实例集合。
- 伸缩配置：创建 ECS 实例的模板，包括镜像、规格、安全组等。
- 伸缩规则：定义扩容或缩容的动作，如增加 2 台实例。
- 伸缩触发任务：按定时、周期或告警（如 CPU 使用率）触发伸缩规则。

## 冷却时间
冷却时间是指伸缩组成功执行伸缩活动后的一段锁定时间。在冷却时间内，伸缩组会拒绝新的伸缩活动请求，避免频繁伸缩导致资源抖动。默认冷却时间为 300 秒。

## 与 SLB 的配合
弹性伸缩通常与负载均衡 SLB 配合使用：新扩容的实例自动加入 SLB 的后端服务器组，缩容时自动从 SLB 摘除，实现「弹性伸缩 + 负载均衡」的完整闭环。
