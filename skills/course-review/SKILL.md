# Course Review Skill

## 目的

确保所有教学文档在发布前通过标准化的质量审查。

## 审查维度

| 维度 | 权重 | 说明 |
|------|------|------|
| 完整性 | 25% | 是否覆盖了所有必要的知识点 |
| 准确性 | 30% | 内容是否准确，有无错误或误导性信息 |
| 结构性 | 20% | 内容组织是否清晰，逻辑是否合理 |
| 可读性 | 25% | 语言是否简洁，表达是否清晰 |

## 工作流程

1. 阅读待审查的文档
2. 按四个维度逐一评估
3. 给出每个维度的评分 (1-5分)
4. 列出具体问题清单
5. 提供可操作的改进建议

## 输出模板

```
## 总体评价: [通过/需修改/重做]

| 维度 | 评分 | 说明 |
|------|------|------|
| 完整性 | X/5 | ... |
| 准确性 | X/5 | ... |
| 结构性 | X/5 | ... |
| 可读性 | X/5 | ... |

## 具体问题
1. ...
2. ...

## 改进建议
1. ...
2. ...
```

## 反模式

- 不要只给评分不给理由
- 不要忽略小错误，所有问题都应记录
- 不要只提问题不给建议
